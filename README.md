# Ekiz's Homepage

一个复古风格的个人静态主页，采用 HTML 3.2 规范编写。

##  特点
- **极简主义**：纯 HTML/JS，无重量级框架。
- **怀旧风格**：模拟早期互联网（Netscape/IE5 时代）的视觉体验。
- **兼容性强**：支持在旧设备或极简浏览器上完美运行。

##  项目结构
```text
├── index.html          # 主入口 (个人简介)
├── projects.html       # 项目归档 (作品集)
├── logs.html           # 开发日志 (更新记录)
├── bookmarks.html      # 常用资源收藏
├── uptime.js           # 系统运行时间计算脚本
├── LICENSE             # MIT 开源协议
└── README.md           # 项目说明文档
```

## 本地运行
直接在浏览器中打开 `index.html` 即可，无需任何环境。
